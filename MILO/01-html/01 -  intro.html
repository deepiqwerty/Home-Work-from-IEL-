What is HTML ?

Hyper Text Markup Language

HTML stands for Hypertext Markup Language, and it is the standard code used to structure a web page and its content.
It is not a programming language; rather, it is a markup language that tells your web browser how to display text, images, links, and other media.

HTML is also used to tell a website, what is an image, text or forms apart from the giving the standard code instruction for the structure of the webpage.

All the words inside a "<>" represents different types of "TAGS". Almost all "TAGS" have an opening tag and a closing tag for example <h1> </h1>
